# Tourism Experience Analytics

Classification, Prediction, and Recommendation System for tourism experiences.

## Streamlit app
The application entrypoint is `app.py` and dependencies are declared in `requirements.txt`.

## Project components
- Rating prediction using Random Forest
- Visit mode classification using Extra Trees
- Content-based attraction recommendation
- Interactive Streamlit dashboard
- Cleaned analytical dataset and trained model artifacts

## Deployment
Use Streamlit Community Cloud with:
- Repository: `kashish-alt0786/Tourism-Experience-Analytics`
- Branch: `main`
- Main file: `app.py`

The model files and dataset files required by `app.py` must also be present in the repository before deployment.
